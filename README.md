# Eventos Acadêmicos - API

API em Node.js e Express para cadastro e listagem de eventos acadêmicos, com banco de dados no Supabase.

Rotas:

- `GET /eventos`
- `POST /eventos`

Variáveis de ambiente: `SUPABASE_URL`, `SUPABASE_KEY` e `FRONTEND_URL`.

Para rodar localmente:

```
npm install
npm start
```
